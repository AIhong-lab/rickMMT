# MMT 天賦原理 · 自動生成天賦盤

輸入西元生日，自動生成專屬於你的 MMT（Mercury Mental Thinking）天賦分析：
六張天賦牌、導師／陰影／家族牌、四大能量分佈與年度策略。

> 純前端網頁，無需後端、無需安裝，開啟 `index.html` 即可使用。所有資料只留在你的瀏覽器（`localStorage` 記住上次輸入）。

---

## 使用方式

### 方法一：直接開啟
用瀏覽器打開 `index.html`，選好生日與查詢年份，按「生成我的天賦盤」。

### 方法二：發佈成網站（GitHub Pages）
1. 把這個 repo 推上 GitHub。
2. `Settings → Pages → Build and deployment → Source` 選 `Deploy from a branch`。
3. Branch 選你的分支、資料夾選 `/ (root)`，儲存。
4. 稍等一下即可用 `https://<帳號>.github.io/<repo>/` 開啟。

## 檔案結構

```
index.html          入口頁面（版面）
assets/style.css     樣式
js/calc.js           計算引擎（所有公式與年輪查表、完全牌、家族關係）
js/data.js           參照資料（四大能量、三種設計、導師/陰影原型、情節、家族9組、解盤步驟）
js/talents.js        每張牌（0~21）的詳細說明 ← 由「MMT上課整理」Google 試算表自動轉出
js/app.js            介面互動與報告產生
```

- 要修改**每張牌的說明**（占星、神話、優勢、非健康能量、職場、兩性、備註、總結、潛意識、財富心智、天賦變現）：請改你的 **Google 試算表「MMT上課整理」**，再跟我說一聲、我幫你同步回 `js/talents.js`（保持「以 Excel 為準」）。
- 要修改四大能量、家族群組、解盤步驟等參照資料：改 `js/data.js`。

報表區塊：牌陣總覽 → 四大能量 → **完全牌** → **家族關係** → 天賦牌詳細 → 導師/陰影/家族牌 → 年度策略 → 解盤步驟。右上角有「🖨️ 列印 / 存成 PDF」。

### 問題聚焦 & 精簡/完整
- **想問的問題**輸入欄：輸入問題後，會依關鍵字判斷主題（感情／工作／財富／家庭／學習／情緒），把每張牌**相關的欄位**放到最前面並高亮（離線關鍵字判斷，非連網 AI）。
- **顯示詳細度**：預設「精簡」——每張牌只顯示天賦優勢、非健康能量與聚焦欄位，其餘收在「展開更多」；切「完整」則全部展開。
- 列印／存 PDF 時一律輸出完整內容。

## 計算方式（依 MMT1階-直版天賦原理）

以 `1984/09/20` 為例：

| 牌 | 計算方式 | 結果 |
|---|---|---|
| **第一張（內在）** | 生日「日」→ 對照表（1~21 原值、22=0、23~31 為各位數字相加） | 20 |
| **第二張（內在）** | 生日所有數字相加，超過 22 減 22（22=0）：`1+9+8+4+0+9+2+0=33 → 33-22=11` | 11 |
| **第三張（內在）** | 西元年各位數字相加＋月＋日（月日不拆），超過 22 減 22：`(1+9+8+4)+9+20=51 → 51-22-22=7` | 7 |
| **外在三張（第四~六張）** | 年輪查表 `grid(月,日)` 為**中間張**，前後連號 `[g-1, g, g+1]` | 20、21、0 |
| **導師牌** | 生命靈數＝生日所有數字相加（但「日」為 11 或 22 時整數計入不拆），反覆相加到 ≤22。落在 10~22 為雙／三導師（家族中 ≤ 生命靈數的成員）。`2016/11/12→14→{5,14}`；`1983/5/22 日22不拆→48→12→{3,12}`；`1984/9/20→33→6` | 6 |
| **陰影牌** | 導師所屬家族中「**非導師牌、也沒有出現在天賦牌**」的號碼（可能 0~2 張） | 15 |
| **家族牌** | 導師的數字根家族群組 | 6、15 |
| **年度策略** | 查詢年份＋月＋日，反覆相加到 ≤21：`2024+9+20=2053 → 2+0+5+3=10` | 10 |
| **四大能量** | **所有天賦牌 + 導師牌** 的數量比例，>25% 為高能量、0 張為 0 能量 | 風71.4%… |

> 外在牌年輪查表已與課程原始查表逐格核對，**100% 相符**。

> 以上結果已對照本人實際排盤逐項驗證一致（天賦牌 `0/7/11/20/20/21`、導師 `6`、陰影 `15`、完全牌 `0/20/21`、能量 `風71.4/火0/水14.3/土14.3`）。

### 年輪查表（第四張牌）
整張月×日對照表可用公式完全重現（已與 PDF 逐格核對）：

```
grid(月, 日) = ((MONTH_BASE[月] - 1 + (日 - 1)) mod 22) + 1        // 值域 1~22，22 = 0
MONTH_BASE = {1:1, 2:10, 3:16, 4:3, 5:11, 6:20, 7:6, 8:15, 9:2, 10:10, 11:19, 12:5}
```

## 可調整的判讀設定（已校準）

以下兩點已依本人實際排盤校準完成，若日後要改可在 `js/calc.js` 調整：

1. **外在三張的連號方向**（`OUTER_MODE`）
   - 已設為 `'center'`：查表值為**中間張**，前後連號 `[g-1, g, g+1]`。
   - （另有 `'forward'` 可選：`[g, g+1, g+2]`。）

2. **四大能量的分母**
   - 已設為「六張天賦牌 + 導師牌（共 7 張）」，見 `analyze()` 中的 `energyCards`。

改完存檔、重新整理網頁就會生效。
