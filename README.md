# MMT 天賦原理 · 自動生成天賦盤

輸入西元生日，自動生成專屬於你的 MMT（Mercury Mental Thinking）天賦分析：
六張天賦牌、導師／陰影／家族牌、四大能量分佈與年度策略。

> 純前端網頁，無需後端、無需安裝，開啟 `index.html` 即可使用。所有資料只留在你的瀏覽器（`localStorage` 記住上次輸入）。

---

## 使用方式

### 方法一：直接開啟
用瀏覽器打開 `index.html`，選好生日與查詢年份，按「生成我的天賦盤」。

### 方法二：發佈成網站（GitHub Pages）
1. 把這個 repo 推上 GitHub。
2. `Settings → Pages → Build and deployment → Source` 選 `Deploy from a branch`。
3. Branch 選你的分支、資料夾選 `/ (root)`，儲存。
4. 稍等一下即可用 `https://<帳號>.github.io/<repo>/` 開啟。

## 檔案結構

```
index.html          入口頁面（版面）
assets/style.css     樣式
js/calc.js           計算引擎（所有公式與年輪查表）
js/data.js           內容資料（0~21 號天賦、四大能量、導師/陰影/家族/情節/解盤步驟）
js/app.js            介面互動與報告產生
data/_source_mmt_notes.md   來源整理（僅供對照，非網頁必需）
```

要修改任何**文字內容**（天賦說明、職場／兩性／財富心智…），改 `js/data.js` 即可，不會動到計算。

## 計算方式（依 MMT1階-直版天賦原理）

以 `1984/09/20` 為例：

| 牌 | 計算方式 | 結果 |
|---|---|---|
| **第一張（內在）** | 生日「日」→ 對照表（1~21 原值、22=0、23~31 為各位數字相加） | 20 |
| **第二張（內在）** | 生日所有數字相加，超過 22 減 22（22=0）：`1+9+8+4+0+9+2+0=33 → 33-22=11` | 11 |
| **第三張（內在）** | 西元年各位數字相加＋月＋日（月日不拆），超過 22 減 22：`(1+9+8+4)+9+20=51 → 51-22-22=7` | 7 |
| **第四張（外在）** | 年輪查表 `grid(月,日)` | 21 |
| **第五、六張（外在）** | 第四張的連號 | 0、1 |
| **導師牌** | 所有數字相加，再反覆相加到個位數：`33 → 3+3=6` | 6 |
| **陰影牌** | 導師同家族中未顯現的號碼（原型對照） | 15 |
| **家族牌** | 導師的數字根家族群組 | 6、15 |
| **年度策略** | 查詢年份＋月＋日，反覆相加到 ≤21：`2024+9+20=2053 → 2+0+5+3=10` | 10 |
| **四大能量** | 六張天賦牌所屬（風火水土）比例，>25% 為高能量、0 張為 0 能量 | 風66.7%… |

### 年輪查表（第四張牌）
整張月×日對照表可用公式完全重現（已與 PDF 逐格核對）：

```
grid(月, 日) = ((MONTH_BASE[月] - 1 + (日 - 1)) mod 22) + 1        // 值域 1~22，22 = 0
MONTH_BASE = {1:1, 2:10, 3:16, 4:3, 5:11, 6:20, 7:6, 8:15, 9:2, 10:10, 11:19, 12:5}
```

## ⚠️ 兩個可調整的判讀點（請你確認）

1. **外在三張的連號方向**（`js/calc.js` 的 `OUTER_MODE`）
   - 目前預設 `'forward'`：第四張＝查表值，第五、六張為其後連號 `[g, g+1, g+2]`。
   - 課程筆記提到「2/29 必定是 15、16、17 連號」，而查表 `grid(2,29)=16`。
     若你的排盤是把查表值當作**中間張**，把 `OUTER_MODE` 改成 `'center'`（會變成 `[g-1, g, g+1]`）。
   - 請對照一張你確定正確的盤，選定其中一種。

2. **四大能量的分母**
   - 目前以「六張天賦牌」為分母計算比例。若你的算法要納入導師牌或其他牌，
     改 `js/calc.js` 的 `analyze()` 傳給 `energy()` 的牌組即可。

改完存檔、重新整理網頁就會生效。
