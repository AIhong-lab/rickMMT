# MMT 天賦原理 · 天賦盤敘述解讀產生器

**直接輸入你已排好的天賦盤數字**（天賦號碼、導師、陰影、四大能量比例、年度策略），
自動生成完整的 MMT（Mercury Mental Thinking）敘述解讀：每張牌的深度解說、導師情節、
陰影原型、家族關係與年度策略。**本工具不進行任何天賦盤計算**，只負責把你手上的數字變成豐富的解讀報告。

> 純前端網頁，無需後端、無需安裝，開啟 `index.html`（或 `dist/mmt-天賦盤-單機版.html` 單一檔案）即可使用。所有資料只留在你的瀏覽器（`localStorage` 記住上次輸入）。

---

## 使用方式

用瀏覽器打開 `index.html`（或單機版 `dist/mmt-天賦盤-單機版.html`），依欄位填入：

| 欄位 | 說明 | 範例 |
|---|---|---|
| **稱呼／姓名** | 可留空，顯示在報告標題與客戶版 PDF | 小明 |
| **天賦號碼** | 你的天賦牌，用逗號或空白分隔（0~21） | `0, 4, 8, 9, 10, 11` |
| **導師** | 導師牌號碼 | `3` |
| **陰影** | 陰影牌，可多張 | `12, 21` |
| **四大能量比例** | 風／火／水／土 各自的百分比 | 28.6 / 28.6 / 14.3 / 28.6 |
| **年度策略號碼** | 年度策略牌（5~16），可留空 | `10` |

按「✦ 生成天賦盤解讀」即可。系統會由這些數字推導：**完全牌**（導師∩天賦）、
**家族關係**（天賦牌觸及的家族群組）、**比較明顯的號碼**（同號 ≥2 張），並附上完整敘述。

### 📱 在 iPad 上離線單機使用
單機版 `dist/mmt-天賦盤-單機版.html` 是完全自帶、離線可用的單一檔案（無任何外部連線）。在 iPad 上：
1. 把該檔存到 iPad（AirDrop／「檔案」App／iCloud 皆可）。
2. 用**能執行網頁的 App**開啟（推薦免費的 **Documents by Readdle**，或 Koder／Textastic）。
   > iPad「檔案」App 的快速預覽常不會執行 JavaScript，按鈕會沒反應，所以要用有瀏覽器核心的 App。
3. 全程免網路；上次輸入會記在該 App 的瀏覽器內。列印／存 PDF 用系統「列印 → 儲存到檔案」。

已加入 iOS 網頁 App 設定（`apple-mobile-web-app-*`、輸入框 16px 防止聚焦時自動放大、`telephone=no` 防止數字被誤判成電話）。

## 檔案結構

```
index.html          入口頁面（版面）
assets/style.css     樣式
js/data.js           參照資料（四大能量、三種設計、導師/陰影原型、情節、家族9組、解盤步驟）
js/talents.js        每張牌（0~21）的結構化欄位 ← 由「MMT上課整理」Google 試算表轉出
js/v15.js            每張牌／導師情節／陰影原型／家族／能量／年度策略的整合敘述 ← 由「MMT上課整理・敘述版 v1.5」轉出
js/app.js            介面互動、輸入解析與報告產生
dist/mmt-天賦盤-單機版.html   把上述全部內嵌成一個檔案的離線單機版
```

> `js/calc.js`（依生日自動排盤的計算引擎）已停用——本工具改為直接輸入數字，不再計算。檔案保留供參考，但不再被載入。

- 要修改**每張牌的說明**（占星、神話、優勢、非健康能量、職場、兩性、備註、總結、潛意識、財富心智、天賦變現）：請改你的 **Google 試算表「MMT上課整理」**，再跟我說一聲、我幫你同步回 `js/talents.js`（保持「以 Excel 為準」）。
- 要修改四大能量、家族群組、解盤步驟等參照資料：改 `js/data.js`。

- 要修改**推導規則**（完全牌＝導師∩天賦、家族群組反查、比較明顯的號碼）或版面：改 `js/app.js`。

報表區塊：牌陣總覽（內在／外在分組）→ 四大能量 → **完全牌** → **家族關係** → 天賦牌詳細（內在／外在逐張）→ 導師/陰影/家族牌 → 年度策略 → 解盤步驟 → **整合總結**（把內在、外在、能量、導師、陰影串成一段話）。

報表右上角有四個按鍵：**「🎴 製作圖卡」**（見下）、**「📖 白話報告」**（把整張盤自動組成一篇順順的白話文章，可再單獨列印／存 PDF）、**「📄 輸出客戶版 PDF」**（簡潔正向、給客戶的天賦報告：牌陣＋四大能量＋導師/陰影/整合總結）與 **「🖨️ 列印完整版」**（含全部解盤內容）。列印類都用瀏覽器「列印 → 另存為 PDF」。

### 🎴 圖卡產生器
生成報告後按「🎴 製作圖卡」展開，可做兩種 1080×1350 直式分享圖卡：**卡型 A · 天賦解盤重點卡**、**卡型 B · 免費天賦速讀卡**。
- 自動帶入暱稱／內外在／導師／陰影，並從報告內容預填文字草稿（可編輯）；每欄顯示剩餘字數，超字變紅並禁止匯出（避免爆版）。
- 即時預覽（縮放顯示），「下載 PNG」以原始 1080×1350 匯出，檔名如 `重點卡_暱稱_YYYYMMDD.png`。
- 手機可操作；iPhone Safari 會改為開新分頁供長按儲存。
- 圖卡配色（深藍漸層＋金 #D9B65C＋Noto Sans TC）與網站配色分離，以圖卡模板為準。
- PNG 匯出用 `html-to-image`，**已內嵌於單機檔**（`js/vendor/html-to-image.js`），離線也能匯出；若元件未載入，匯出鍵會提示「需要網路連線」而非靜默失敗。字型 Noto Sans TC 由 Google Fonts 載入，離線時自動退回系統中文字型（PingFang TC 等）。

> 白話報告是離線自動組成（不串 AI）：由你輸入的數字，把四大能量→最強天賦→內外整合→導師方向→陰影功課→年度心態→結語串成一篇文章。

### 問題聚焦 & 精簡/完整
- **想問的問題**輸入欄：輸入問題後，會依關鍵字判斷主題（感情／工作／財富／家庭／學習／情緒），把每張牌**相關的欄位**放到最前面並高亮（離線關鍵字判斷，非連網 AI）。
- **顯示詳細度**：預設「精簡」——每張牌只顯示天賦優勢、非健康能量與聚焦欄位，其餘收在「展開更多」；切「完整」則全部展開。
- 列印／存 PDF 時一律輸出完整內容。

## 推導規則（由輸入值直接得出，非計算排盤）

本工具不做生日排盤計算；下列項目只是把你輸入的數字做簡單推導與查表：

| 項目 | 規則 |
|---|---|
| **完全牌** | 導師號碼同時出現在天賦牌中（導師∩天賦）。例：導師 5、天賦有 14→非完全；導師 14、天賦有 14→完全 14。 |
| **比較明顯的號碼** | 同一天賦號碼出現 ≥2 張（非完全牌），優勢加成。 |
| **家族關係** | 依天賦牌反查所屬家族群組（相同數字根，見 `js/data.js` 的 `FAMILIES`），並標示到齊／缺牌。 |
| **家族牌** | 導師所屬家族的成員。 |
| **四大能量高低** | 直接採用你輸入的百分比：>25% 為高能量、0% 為 0 能量、其餘為一般。 |
| **年度策略** | 直接採用你輸入的策略號碼（5~16），對應敘述版 v1.5 的年度策略段落。 |

> 內容敘述採用「MMT上課整理・敘述版 v1.5」。
